# 文档索引

这个目录分两部分：**使用者文档**（放在这里）和**开发文档**（放在 [`dev/`](dev/)）。

## 使用者文档

| 文档 | 什么时候看 |
|---|---|
| [使用手册.md](使用手册.md) | 第一次用这个工具，或者想知道某个功能怎么操作。覆盖安装、画布操作、连线、参数面板、校验、导出、从代码导入、设置、日志、全屏、常见问题 |
| [控件参考.md](控件参考.md) | 想知道某个控件是干什么的、要填哪些参数、会生成什么代码。76 个控件按分类列出 |

建议按这个顺序看：

1. 先用根目录 [`README.md`](../README.md) 了解项目整体，或者直接看[使用手册](使用手册.md)的「五分钟上手」。
2. 搭画布时对照[控件参考](控件参考.md)查控件。
3. 遇到问题翻[使用手册](使用手册.md)的「常见问题与排查」。

## 开发文档

`dev/` 里是**看代码 / 改代码**才需要的东西。**用这个工具不需要看它们。**

| 文档 | 内容 |
|---|---|
| [dev/详细设计.md](dev/详细设计.md) | 工具本身的设计文档：设计决策表、数据模型、代码生成规则 |
| [dev/API核对报告.md](dev/API核对报告.md) | 工具里定义的控件与实际 ScriptAgent4MindustryExt API 的一致性核对结论 |
| [dev/SA4MDT-深入分析.md](dev/SA4MDT-深入分析.md) | ScriptAgent4MindustryExt 内部机制与 API 面的深入分析 |
| [dev/新控件API核对.md](dev/新控件API核对.md) | 逐个控件的 API 离线核对记录 |

这几份是**历史研究笔记**：写于工具开发过程中，用来确定「这个控件到底该生成什么代码」。里面的结论已经落到 `src/frontend/js/catalog/` 的控件目录里了，文档本身保留下来是为了记录**为什么这么写**。

> 有个别结论后来被推翻了（比如 `Fx` 到底要不要显式 import）。**以代码为准**，文档只作参考。
